POST Generate Forecast

/api/forecast/

Generate sales forecasts for one or more products.

Request Body
{
    "product_id": "SKU00001",
    "periods": 30
}

// OR for multiple products:

{
    "product_ids": ["SKU00001", "SKU00002", "SKU00003"],
    "periods": 30
}
Response
{
    "status": "success",
    "count": 1,
    "forecasts": [
        {
            "product_id": "SKU00001",
            "product_name": "Black Jackets",
            "total_predicted_units": 120.5,
            "avg_daily_units": 4.02,
            "confidence_score": 0.75,
            "forecast_start": "2026-02-09",
            "forecast_end": "2026-03-10",
            "daily_forecast": [...]
        }
    ]
}

GET Risk Analysis

/api/risk-analysis/

Get inventory risk analysis for products.

Query Parameters
  • category - Filter by product category
  • risk_level - Filter by risk level (high/medium/low)
  • limit - Number of results (default: 100)
Example
GET /api/risk-analysis/?category=Tops&risk_level=high&limit=10
Response
{
    "status": "success",
    "summary": {
        "total_products": 100,
        "high_risk_products": 20,
        "high_risk_percentage": 20.0
    },
    "products": [...]
}
Try it now

GET Get Recommendations

/api/recommendations/

Get actionable recommendations based on trends and risk.

Query Parameters
  • type - emerging/declining/all (default: all)
  • limit - Number of results (default: 20)
Example
GET /api/recommendations/?type=emerging&limit=5

GET Product Details

/api/product/<sku>/

Get complete intelligence for a single product.

Example
GET /api/product/SKU00001/
Response
{
    "status": "success",
    "product": {
        "sku": "SKU00001",
        "name": "Black Jackets",
        "category": "Outerwear",
        "price": 89.99
    },
    "inventory": {...},
    "forecast": [...],
    "risk": {...},
    "recent_sales": [...]
}
